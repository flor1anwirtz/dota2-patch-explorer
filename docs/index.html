Coverage and definitionsCollection dates, match eligibility and how to read the rates.

Which matches qualify?

The tracker counts public ranked matches recorded by OpenDota with a known winner. The default duration filter includes games lasting at least 20 minutes. Select All durations to include shorter matches.

How are rates calculated?

Radiant win rate is the share of matches Radiant won. The side-to-side gap is the absolute difference between Radiant’s and Dire’s win rates. The patch change subtracts the first patch’s Radiant rate from the second’s, in percentage points. Its approximate 95% interval combines two Wilson score intervals and treats matches as independent.

How are ranks grouped?

The match’s average medal determines its rank group. All ranks includes matches with an unknown medal; select Unknown rank to see those games separately.

What does coverage mean?

A covered day has a successful count for its UTC date and patch. On a patch release day, a match’s start time determines which patch it belongs to. Partial coverage means some dates still need counts. The latest day shown can be later than a gap.
